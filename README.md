# AIM:
To develop and model a simple Student Online Exam Registration System using StarUML and represent its system structure and behavior using various UML diagrams.
# SRS (Procedure):

1. Open StarUML and create a new project for the Student Online Exam Registration System.
2. Create a Use Case Diagram with actors such as Student, Exam Coordinator, and Administrator.
3. Add use cases such as Login, Register for Exam, View Exam Schedule, Select Subject, Make Payment, Download Hall Ticket, View Exam Status, Manage Exams, and Logout.
4. Create a Class Diagram with classes such as Student, Exam, Subject, Registration, Payment, HallTicket, and Administrator, including their attributes and methods.
5. Create an Activity Diagram to represent the step-by-step flow from student login and exam selection to registration, payment, hall-ticket generation, and logout.
6. Create a Package Diagram to organize the system into Student Management, Exam Management, Registration, Payment, Authentication, and Database packages.
7. Create a Communication Diagram to show the interaction between Student, Exam Registration System, Exam, Registration, Payment, and HallTicket during online exam registration.
8. Create a Sequence Diagram to represent the message flow during an online exam registration transaction, such as selecting an exam, registering, making payment, and generating a hall ticket.
9. Check all diagrams, add the required relationships, associations, dependencies, include/extend relationships, and labels, and arrange the elements neatly.
10. Save the StarUML project and export the completed diagrams as images or PDF for documentation.
